# Contribuir

Las contribuciones prioritarias son cotejos contra el facsímil, correcciones de transcripción, identificación de referencias cruzadas, segmentación de ejemplos y revisión lingüística.

## Regla de evidencia

Toda corrección debe indicar `record_id`, página impresa, página PDF y lectura propuesta. Cuando el facsímil sea ambiguo, no se fuerza una solución: se conserva la duda editorial.

## Estados sugeridos

`unverified_ocr` → `facsimile_checked` → `diplomatic_verified` → `linguistically_reviewed`.

Las traducciones españolas y notas interpretativas deben identificarse como editoriales. No se copiarán de manera sistemática traducciones protegidas de ediciones contemporáneas sin autorización expresa.
