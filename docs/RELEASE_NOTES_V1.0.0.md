# Rarámuri Histórico Digital 1.0.0

RHD 1.0.0 fija a **Steffel 1791/1809** como implementación de referencia reusable de una edición histórico-digital científica, computacional e IA-asistida, bajo política **machine-only** y con incertidumbre explícita como estado terminal legítimo.

## Contenido científico congelado

- 2,495 candidatos documentales con disposición.
- 1,965 artículos activos y 1,965 transcripciones diplomáticas IA-asistidas.
- 482 casos PHIL terminales: 284 `confirmed_ai_assisted`, 152 `corrected_ai_assisted`, 46 `unresolved_after_ai_recollation`.
- 298 relaciones diacrónicas conservadas como `candidate`, con calibración contra 5,066 emparejamientos nulos deterministas.
- Anexos Steffel 369–374 cerrados en alcance machine-only: numeración, 22 fórmulas paralelas y Padre Nuestro, con 43 incertidumbres residuales explícitas.
- TEI RHD rica y proyección TEI Lex-0 estricta, validada contra TEI Lex-0 0.9.5.
- Replicación industrial completa sobre Tellechea 1826: 205/205 páginas, sin rediseño del núcleo RHD y sin atribuciones humanas fabricadas.

## Alcance epistemológico

Este release no afirma revisión humana independiente. Ningún resultado IA-asistido se presenta como `human_verified`. Los estados irresueltos se preservan cuando la evidencia no permite una lectura única.

## Archivo persistente

Este GitHub Release congela la versión estable `v1.0.0`. El gate final de **archivo/DOI persistente** permanece separado: RHD sólo se declarará 100% cuando exista un registro archivado con identificador persistente real y se compruebe su correspondencia con este tag/commit y el manifiesto de integridad.
