## Por qué se conserva

Se mantiene únicamente como registro de historia metodológica y para que el repositorio haga explícito que el cambio de porcentaje no fue una manipulación retrospectiva. El cambio de alcance elimina como requisito de cierre una revisión humana que ya no forma parte del diseño científico del proyecto.

En el alcance vigente:

- los 482 casos PHIL tienen estado computacional terminal;
- `unresolved_after_ai_recollation` es una salida legítima y no una tarea humana pendiente;
- la edición se declara computacional e IA-asistida, nunca humanamente validada;
- la terminación se mide con la matriz machine-only vigente.

No utilizar esta matriz para reportar el avance actual del proyecto.
