# Release 0.2.0 — cobertura integral

La versión 0.2.0 elimina el límite funcional de 60 entradas del MVP y procesa el rango lexicográfico completo del OCR suministrado.

Resultado reproducible actual: 2,495 candidatos de artículo, de los cuales 1,607 corresponden a alemán→rarámuri y 888 a rarámuri→alemán. Las 60 anclas anteriores preservan exactamente sus identificadores. Se añade una tabla de todas las líneas OCR de los dos diccionarios, exportaciones completas JSON/XML/SQLite, TEI de trabajo y secciones OCR separadas para el apéndice y la muestra lingüística.

El conteo de candidatos no equivale al conteo crítico definitivo de entradas. Toda la capa automática permanece pendiente de cotejo facsimilar.
