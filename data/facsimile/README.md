# Facsimile page-layout layer

`page_layout_301_317.csv` records the first explicit layout model for the German→Rarámuri dictionary pages currently under detailed review.

Pages 301–317 (PDF pages 11–27) were visually confirmed as two-column dictionary pages. The table records left/right columns and their normal page reading order. This structural layer exists because the supplied OCR does not reliably preserve column order: linear OCR line sequence must not be treated as article-body sequence.

The layout assessment is AI-assisted visual review and remains `human_verified=false`. It is structural evidence, not a full transcription of the columns.
